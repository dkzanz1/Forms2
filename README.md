An interactive React application built to explore component state management, controlled form inputs, and event handling using React hooks.

> **Context:** Developed as a practical hands-on exercise to master bridging user input data with React component state via `useState`, managing form submissions, and handling dynamic input validation.

---

## 🛠️ Key Architectural & React Learnings

- **Controlled Components:** Utilized React state (`useState`) to capture, track, and update user inputs in real-time as state objects.
- **Event Handling:** Implemented custom submission handlers (`onSubmit`) to process form data and prevent default browser page reloads.
- **Dynamic State Flow:** Structured reactive input elements that respond instantly to user interactions and state changes.

---

## 💻 Tech Stack

- **Frontend Core:** React, JavaScript (ES6+), HTML5, CSS3
- **Tooling & Quality:** Node.js, npm, GitHub Actions (Node.js CI runner)
